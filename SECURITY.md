# Security Policy

This repository is a fork of [MatthewWid/better-sse](https://github.com/MatthewWid/better-sse).

- Vulnerabilities in the **original project**: please report them upstream, following the policy at <https://github.com/MatthewWid/better-sse/security>.
- Issues specific to **this fork** (CI, configuration, changes made here): open a private advisory via the **Security** tab of this repository.
